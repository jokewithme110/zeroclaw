# 安装说明 - 快速安装
1、按照模板填写正确的provider信息及channel信息即可快速使用，其它配置保持默认

2、将示例配置更名
```shell
mv config_example.toml config.toml
```

3、环境变量安装,在android等系统上要指定
```shell
# 根据自己系统指定
export HOME=/plugin/vdb
export ZEROCLAW_CONFIG_DIR=/plugin/vdb/.zeroclaw
mv config.toml ~/.zeroclaw/config.toml
```

4.启动
```
./zeroclaw daemon

```
